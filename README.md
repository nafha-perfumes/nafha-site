# Nafha Perfume Gallery
Static site. Everything is in `index.html`.
- Products: the `P` array in the script. Each row: name, Arabic name, category, [price35, price60, price100], notes, description.
- Images: the `productImages` array, same order as `P`.
- Sizes: `sizes=[35,60,100]`.
- WhatsApp number: search `201024875959`.
Push to `main` and Vercel deploys automatically.
